# Сайт Consult Invest ITIC

Статический сайт на [Astro](https://astro.build) с админкой [Decap CMS](https://decapcms.org).
Новости, проекты, мероприятия и публикации в СМИ хранятся как Markdown-файлы в `src/content/`.
Админка редактирует эти файлы и сохраняет изменения коммитами в репозиторий.

## Запуск на компьютере

```bash
npm install
npm run dev        # сайт: http://localhost:4321
npm run cms        # во втором терминале: локальный сервер админки
```

Админка: http://localhost:4321/admin/index.html (на боевом сайте – /admin/). Локально вход не нужен, изменения сразу пишутся в файлы.

Сборка: `npm run build`, готовый сайт лежит в `dist/`.

## Где что лежит

| Что | Где |
|---|---|
| Новости | `src/content/news/*.md`, картинки в `public/uploads/news/` |
| Проекты | `src/content/projects/*.md` |
| Мероприятия | `src/content/events/*.md` |
| CI ITIC в СМИ | `src/content/media/*.md`. Пункт меню появляется, когда есть хотя бы одна публикация |
| Офисы, представители, реквизиты | `src/data/site.ts` |
| Главная | `src/pages/index.astro` |
| Стили | `src/styles/global.css` |
| Политика конфиденциальности | `src/pages/privacy/index.astro` |
| Настройки админки | `public/admin/config.yml` |

## Админка в интернете

1. В `public/admin/config.yml` в `backend.repo` указать `владелец/репозиторий`.
2. Для входа через GitHub нужен OAuth-прокси: небольшой сервис, который выдает токен GitHub.
   Варианты: Netlify (встроенный), Cloudflare Worker или свой сервер. Адрес прокси прописать в `backend.base_url`.
3. Редакторам нужен аккаунт GitHub с доступом к репозиторию.
4. Режим `editorial_workflow`: запись проходит статусы «Черновик → На проверке → Готово», на сайт попадает после публикации.

## Хостинг

Сайт статический, подойдет любой хостинг. Требования:
- доступность из России и Китая без VPN: шрифты уже лежат на сайте, Google Fonts и внешние скрипты на страницах не используются;
- форма заявки: обработчик на сервере в РФ (152-ФЗ, данные граждан РФ записываются в базы на территории РФ).

## Перенос с Tilda

- Новости перенесены из ленты Tilda (Потоки) с обложками.
- После переезда настроить 301-редиректы со старых адресов Tilda на `/news/...`.
