# e-shutov.ru

Личный сайт-досье Евгения Шутова. Русская и английская версии.
Статические файлы, без фреймворков и без внешних зависимостей: шрифты лежат локально,
запросов на сторонние домены сайт не делает вообще.

## Как устроено

```
src/content.mjs    ← весь текст сайта, RU и EN. Правится только здесь
src/render.mjs     ← разметка страницы
src/styles.css     ← дизайн-система
src/app.js         ← меню, подсветка навигации, появление блоков
src/favicon.svg    ← иконка вкладки
build.mjs          ← сборка

index.html         ┐
en/index.html      │
404.html           ├ результат сборки — эти файлы и заливаются на хостинг
assets/            │
sitemap.xml        │
robots.txt         ┘
```

## Правка и сборка

Текст меняется в `src/content.mjs` — объект `ru` и его зеркало `en`.
Структуры обеих версий должны совпадать. После правки:

```bash
node build.mjs
```

Требуется только Node.js — ни `npm install`, ни сборщиков.

## Публикация на reg.ru

Сайт полностью статический, поэтому достаточно скопировать файлы в корень сайта
(на reg.ru это обычно `/public_html` или `/www/e-shutov.ru`) по FTP или через файловый
менеджер панели управления.

Заливать нужно:

```
index.html
404.html
favicon.svg
robots.txt
sitemap.xml
en/
assets/
```

Папки `src/` и файла `build.mjs` на хостинге быть не должно — это исходники.

Старую React-сборку (`assets/index-*.js`, `assets/index-*.css`) перед заливкой удалите,
иначе в папке `assets` останутся файлы от предыдущего сайта.

## Что можно добавить, и сайт сам это подхватит

Сборка проверяет наличие файлов и включает соответствующие блоки только тогда,
когда файл действительно лежит на месте. Ничего не сломается, если файла нет.

| Файл | Что появится |
|---|---|
| `assets/img/portrait.jpg` | Портрет на первом экране. Без него первый экран чисто типографический. Нужен вертикальный кадр 4:5, минимум 800×1000 |
| `assets/shutov-cv.pdf` | Кнопка «Резюме PDF» на первом экране |
| `assets/img/work-intervision.jpg` | Фотография в блоке «Интервидение-2025» |
| `assets/img/work-sco.jpg` | Фотография в блоке «Бизнес-инкубатор ШОС 2025» |
| `assets/img/work-bridge.jpg` | Фотография в блоке «Russia Bridge Program» |
| `assets/img/work-rakez.jpg` | Фотография в блоке «RAKEZ» |
| `assets/img/work-agora.jpg` | Фотография в блоке «AGORA Global Business Club» |

Фотографии проектов — горизонтальные, 16:9, от 1600 px по ширине.
На сайте они показываются обесцвеченными и наливаются цветом при наведении.

После добавления файлов снова выполните `node build.mjs`.

## Что учтено

- Две языковые версии с корректными `hreflang` и переключателем
- Микроразметка `schema.org/Person`, `sitemap.xml`, `robots.txt`
- Тёмная тема по системной настройке
- Стиль для печати: страница печатается и сохраняется в PDF как аккуратное резюме
- Клавиатурная навигация, ссылка «Перейти к содержанию», `prefers-reduced-motion`
- Шрифты Source Serif 4, IBM Plex Sans и IBM Plex Mono подключены локально —
  сайт не зависит от доступности Google Fonts

## Проверить перед публикацией

Данные в тексте взяты из резюме. Отдельно стоит перепроверить формулировку должности
в `src/content.mjs` (`hero.role` и первый пункт `career.jobs`): в открытых источниках
Consult Invest ITIC руководителем компании указана Татьяна Селиверстова как основатель,
поэтому формулировка «руководитель российского офиса — Country Manager, Russia»
корректнее и безопаснее, чем «генеральный директор» без уточнения.
